# Employee-Management-System

A simple and interactive Employee Management System built using **React.js** that allows users to manage employee records through a user-friendly interface. The application uses **Browser Local Storage** to store data persistently without requiring a backend or database.

## 🚀 Features

- **Add Employees:** Add new employee records with the required details.
- **View Employees:** Display employee information in an organized interface.
- **Update Records:** Edit existing employee details.
- **Delete Employees:** Remove employee records when they are no longer needed.
- **Local Storage:** Automatically preserve data in the browser, even after refreshing the page.
- **Responsive UI:** Simple and intuitive user interface for easy navigation.

## 🛠️ Tech Stack

- **React.js** – Building the user interface and reusable components.
- **JavaScript (ES6+)** – Application logic and functionality.
- **HTML5** – Structuring the application.
- **CSS3 / Tailwind CSS** – Styling and layout *(mention only what you used)*.
- **Browser Local Storage** – Storing employee data locally.

## ⚙️ Installation and Setup

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

### 2. Navigate to the Project Directory

```bash
cd YOUR-REPOSITORY
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal to access the application. If your project uses Create React App instead of Vite, use `npm start`.

## 💾 Data Storage

This project uses the browser's **Local Storage API** to save employee information.

- Data remains available after refreshing the page.
- No backend server or external database is required.
- Data is stored locally in the browser and is not shared across different browsers or devices.
- Clearing the browser's site data may permanently remove the saved records.
